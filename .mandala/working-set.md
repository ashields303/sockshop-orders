### CAT-3: Show a low-stock badge on product tiles
Items with fewer than five in stock should carry a low-stock badge on the listing. The badge must appear on any product tile where stock count is below five, so shoppers can act on scarcity at a glance.
Acceptance criteria:
- Given an item with three units in stock exists in the catalogue, when the product listing page renders that item's tile, then the tile displays a low-stock badge
Test notes:
- (unit) Test the badge visibility logic in isolation: assert that the badge is shown when stock < 5 and hidden when stock >= 5. Cover boundary values 0, 4 (badge shown) and 5, 99 (badge hidden).
- (integration) Verify the stock count flows from the catalogue service response through to the rendered tile component without being dropped or miscast.
- (manual) In the running Sock Shop front-end, find a product with fewer than five items in stock and confirm the badge is visible on the listing tile. Then find a product with five or more in stock and confirm no badge appears.

### CAT-2: Filter the catalogue by tag
Shoppers want to see only, for example, sports socks. The listing should accept a tag filter and return only items that carry that tag.
Acceptance criteria:
- Given the catalogue contains items tagged 'sport' and items tagged 'formal', when the listing is requested with the filter tag=sport, then only items tagged 'sport' are returned and no 'formal' items appear
Test notes:
- (unit) Unit-test the tag-filtering logic: given a list of items with mixed tags, assert that passing tag='sport' returns only sport-tagged items and that passing no tag returns all items.
- (integration) Call the catalogue listing endpoint (as consumed by the front-end via GET /orders or the catalogue service equivalent) with a tag query parameter and assert the response body contains only items matching that tag. Test with an unknown tag to confirm an empty list is returned rather than an error.
- (manual) In the running Sock Shop front-end, select the 'sport' tag filter on the product listing page and confirm only sport-tagged socks are displayed. Then clear the filter and confirm all products return.
- (e2e) Drive a browser through tag selection (e.g. 'sport'), assert tile count matches the number of sport-tagged items seeded in the test catalogue, then switch to 'formal' and assert the count changes accordingly.
